# Code of Conduct

This project is small and casual, but the basic rules still apply.

## Be kind

Disagreements happen — about which game to build next, what palette is
ugly, whether `let` or `const` is "the right choice". That's fine. What's
not fine:

- Personal attacks, slurs, harassment, doxxing, threats.
- Sustained patterns of belittling other contributors or users.
- Trolling for trolling's sake.

## Scope

This applies in any space tied to the project — issues, pull requests,
discussions, code reviews, commit messages, and any communication
channel set up for the project.

## Enforcement

If something happens — to you or to someone else — please open an issue
with the `conduct` label, or email phktistakis@gmail.com. Reports are
read in private. The maintainers may remove comments, lock threads,
revert commits, or, in serious cases, ban contributors.

We try to follow the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) in spirit;
that's the canonical reference if you want one.
