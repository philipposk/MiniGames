# Mini Games 🎮

A collection of fun, interactive mini games built with HTML, CSS, and JavaScript.

## Games

- **Bounce Ball** ⚽ - Classic paddle and ball game. Break all the bricks!
- **Color Clash** 🎨 - Test your color perception and timing skills.
- **Stick Runner** 🏃 - Minimalist stick figure action game. Jump and survive!
- **The Rising** 🧊 - Stack humans to escape rising water. A survival challenge.

## How to Play

Each game is self-contained in its own folder. Simply open the `index.html` file in a web browser, or use a local server:

```bash
python3 -m http.server 8000
```

Then navigate to the game folder in your browser.
