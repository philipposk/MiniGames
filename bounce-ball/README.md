# Bounce Ball Game

A classic bounce ball game where you control a paddle to bounce a ball and break bricks!

## Features

- Classic paddle and ball mechanics
- Breakable bricks with different colors
- Score tracking
- Lives system
- High score persistence
- Smooth ball physics
- Responsive touch and mouse controls

## How to Play

1. Move your mouse or finger to control the paddle
2. Bounce the ball to break all the bricks
3. Don't let the ball fall off the bottom!
4. Break all bricks to advance to the next level
5. Each level gets faster

## Running the Game

Simply open `index.html` in a web browser, or use a local server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
