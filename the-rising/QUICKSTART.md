# Quick Start Guide - The Rising

## 🚀 Test on Your Phone in 60 Seconds

### Step 1: Start the Server

Open terminal in the `the-rising` folder and run:

```bash
python3 server.py
```

You'll see something like:
```
📱 Access from your phone:
   → http://192.168.1.100:8000
```

### Step 2: Open on Your Phone

1. **Make sure your phone is on the same WiFi** as your computer
2. Open your phone's browser (Safari, Chrome, etc.)
3. Type the address shown in the terminal (e.g., `http://192.168.1.100:8000`)
4. Game loads instantly!

### Step 3: Play!

- **Tap anywhere** to place humans
- **Stack them** to escape the rising water
- **Reach the green line** before you run out of survivors

## 🔧 Troubleshooting

### Can't connect from phone?

1. **Check WiFi**: Both devices on same network?
2. **Check firewall**: Temporarily disable to test
3. **Try different IP**: Your computer might have multiple IPs
   - Run `ifconfig` (Mac) or `ipconfig` (Windows)
   - Try each 192.168.x.x address

### Game not loading?

1. **Refresh the page** (pull down on mobile)
2. **Clear browser cache**
3. **Try a different browser** (Chrome, Firefox, Safari)

### Game is laggy?

1. **Close other apps** on your phone
2. **Update your browser**
3. Game auto-adjusts to screen size and performance

## 🌐 Deploy Online (Free)

### Netlify (Easiest)
1. Go to [netlify.com](https://netlify.com)
2. Drag and drop the `the-rising` folder
3. Get a live URL instantly
4. Share with anyone!

### GitHub Pages
1. Create a GitHub repo
2. Upload the `the-rising` folder
3. Enable Pages in Settings
4. Access at `username.github.io/repo-name`
